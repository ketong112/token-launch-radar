A token-launch radar: ranks 120 pre-token DeFi protocols from a sealed DefiLlama snapshot by implied launch value, with a concrete farm plan for each, on a sortable dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <path-to-snapshot.json>
```
